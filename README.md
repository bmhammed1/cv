# CV — Médecin (Maroc)

Curriculum vitae professionnel trilingue : **Français** (par défaut), **العربية** (RTL) et **English**.

- Ouvrir `index.html` dans un navigateur, choisir la langue en haut de page.
- Lien direct par langue : `index.html?lang=fr`, `?lang=ar`, `?lang=en`.
- Bouton **PDF** : imprime le CV au format A4 (choisir « Enregistrer en PDF »).

## Personnaliser
Toutes les informations se trouvent dans le bloc `<script>` de `index.html` :
- `PERSON` : téléphone, e-mail, LinkedIn, N° CNOM, N° INPE, photo (ex. `photo.jpg`).
- `CONTENT.fr`, `CONTENT.ar`, `CONTENT.en` : textes traduits de chaque section.
